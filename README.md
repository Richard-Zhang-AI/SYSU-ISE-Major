## 🛠️ 技术栈速览 (Tech Stack Overview)

本仓库项目涉及的技术和工具主要包括：

*   **编程语言:** `C++`, `Python`, `Java`, `SQL`,  `Assembly`
*   **专业软件:** `MATLAB`, `Simulink`, `Vivado`, `MySQL`
*   **框架与库:** `OpenCV`, `Numpy`, `ROS`

## 🚀 如何使用 (How to Use)

1.  **克隆仓库到本地:**
    ```sh
    git clone https://github.com/SYSUzrc/Major-Assignments.git
    ```
2.  **浏览项目:**
    进入你感兴趣的课程文件夹，查看对应的代码、报告和文档。
    ```sh
    cd "Major-Assignments/课程文件夹名称"
    ```

## 🤝 贡献与交流 (Contributing)

欢迎通过 `Issue` 提出问题或建议。如果你发现了 bug，或者有更好的实现方式，也欢迎提交 `Pull Request`。
（不过我大概率不改了（bushi））

1.  Fork 本仓库
2.  创建你的分支 (`git checkout -b feature/AmazingFeature`)
3.  提交你的更改 (`git commit -m 'Add some AmazingFeature'`)
4.  推送到分支 (`git push origin feature/AmazingFeature`)
5.  打开一个 Pull Request
